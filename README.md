Mojang在2022年6月8日发布的[Minecraft: Java & Bedrock -- Launch Trailer](https://www.youtube.com/watch?v=g6I6B_xa9aM)视频中使用了第三方mod来宣传Java版，其中就有机械动力。而Mojang看起来根本不会玩机械动力，在视频中搭出了令人匪夷所思的机器，被新生代机械动力工程师笑话了四年，还被The Create Team永久载入史册了
![Enigma](docs/enigma.png)
但你有没有想过，如果……**Mojang不是乱搭的呢？**

> 某种程度上我是不是在强行给ojng台阶下啊

## 介绍

本模组为“Mojang的神秘机械”注册了多方块结构，并为此引入了一套神秘的设定。玩家可以通过Minecraft原版的进度系统和来自Create的思索系统一步步发掘隐藏的神秘，并最终解开Mojang的谜题，掌握神秘机械的力量……

### 开始

你将在思索任意场景时获得“俺寻思之力”成就，进而解锁本模组进度页。

同时，在古代城市你也可以找到残破的神秘机械结构与神秘蓝图，协助你了解它的样貌。

在原版进度系统和机械动力思索系统的引导下，你将一点点了解何为神秘机械，以及它背后所蕴含的，无限的力量。

> 私以为我的引导写的已经尽力了，但这个模组脱离引导游玩会失去很多乐趣。所以我个人还是不太推荐查MC百科，除非你真没招了。

### 注意
本模组默认可以在**生存模式**下获取**创造模式物品**。这对以机械动力为主线的整合包来说未必合适。

整合包作者可以通过KubeJS以修改或禁用部分配方或物品，进行平衡性调整。

> 当然我强烈建议每个在冒险包里塞机械动力作为必需流程的作者就这样吧，你强行给冒险包塞机械动力已经够玩家受的了。让孩子吃点好的吧。
